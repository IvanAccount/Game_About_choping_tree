# My project

Проект Unity для демонстрации лесного 3D-проекта с видом от первого лица, рубкой деревьев и сценами меню и игры.

## Описание проекта

Это небольшая прототипическая игра в жанре лесного выживания / симулятора рубки. Игрок перемещается по сцене от первого лица, может прыгать, смотреть вокруг и рубить деревья, которые постепенно ломаются после нескольких ударов.

Основная идея:
- исследовать сцену от первого лица;
- находить деревья по лучу из камеры;
- нажимать клавишу взаимодействия для нанесения ударов;
- после нужного количества ударов дерево начинает анимацию падения и затем удаляется из сцены.

## Основные механики

- Передвижение от первого лица
- Поворот камеры мышью
- Прыжок и гравитация
- Лучевой поиск дерева перед персонажем
- Система ударов по деревьям
- Кулдаун между ударами
- Анимация рубки и падения дерева
- Переход между сценами: Main Menu -> Game Scene

## Управление

- W, A, S, D — движение
- Mouse — поворот камеры
- Space — прыжок
- E — взаимодействие / рубка дерева

## Структура проекта

- `Assets/Scenes/` — сцены проекта
- `Assets/Scripts/` — основной игровой код
- `Assets/Animation/` — анимации и контроллеры
- `Assets/SimpleNaturePack_URP/` — готовые 3D-модели окружения и деревьев
- `ProjectSettings/` — настройки Unity проекта

## Ключевые скрипты

- [Assets/Scripts/PlayerMovement.cs](Assets/Scripts/PlayerMovement.cs) — управление персонажем, камера, прыжок и гравитация
- [Assets/Scripts/TreesInteraction.cs](Assets/Scripts/TreesInteraction.cs) — логика рубки деревьев, лучевой детект, количество ударов и удаление после анимации
- [Assets/Scripts/AxeAnimationController.cs](Assets/Scripts/AxeAnimationController.cs) — управление анимацией топора
- [Assets/Scripts/InteractionWithObjects.cs](Assets/Scripts/InteractionWithObjects.cs) — базовый прототип взаимодействия с объектами
- [Assets/Scripts/MainMenuSceneLoader.cs](Assets/Scripts/MainMenuSceneLoader.cs) — загрузка игровой сцены из меню

## Сцены

В проекте предусмотрены минимум две сцены:

- MainMenu — стартовое меню
- GameScene / SampleScene — игровая сцена

Для перехода между сценами используется `SceneManager.LoadScene(...)`.

## Требования

- Unity 6000.4.10f1 или совместимая версия
- URP-пакет в проекте
- Unity Input System

## Запуск проекта

1. Откройте проект в Unity.
2. Убедитесь, что сцена меню выбрана как стартовая.
3. Нажмите Play.
4. На кнопке в главном меню выберите старт игры.
5. В игре подойдите к дереву и нажмите `E`, чтобы рубить его.

## Примечание

- системой инвентаря;

- несколькими уровнями и сценами;
- дополнительными эффектами звука и анимации.
